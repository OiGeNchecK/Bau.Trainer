# Bauplan-Trainer

Інтерактивний курс читання німецьких будівельних планів: від «що таке 1:100» до рівня Bauleiter.
4 рівні, 23 аркуші з кресленнями, розрахунками і тестами, словник.

**Відкрити:** https://oigencheck.github.io/Bau.Trainer/

## Встановити як застосунок

- **iPhone / iPad:** відкрий посилання в Safari → «Поділитися» → «На початковий екран».
- **Android:** відкрий у Chrome → меню ⋮ → «Встановити застосунок».
- **Комп'ютер (Chrome, Edge):** іконка встановлення в адресному рядку.

Після першого відкриття працює без інтернету. Прогрес зберігається на пристрої.

## Розробка

Вміст лежить у корені: `index.html` (оболонка і стилі), `draw.js` (креслення), `l0.js`–`l3.js` (рівні).
Після змін збери версію для GitHub Pages:

```bash
python3 build.py
```

Скрипт оновлює теку `docs/`, з якої GitHub Pages віддає сайт.
